      Conectar Instagram (API oficial) · 20–30 min, una sola vez

      Con esto el robot trae fotos, carruseles, likes y comentarios de @missuniverse y de las candidatas con cuenta profesional, y los ordena en la Galería.

      1. Tu Instagram debe ser profesional (Creador o Empresa): Instagram → Configuración → Tipo de cuenta. Puede ser la cuenta nueva de concursos.
      2. Vincúlalo a una Página de Facebook (crea una página simple si no tienes): en la página, Configuración → Cuentas vinculadas → Instagram.
      3. Entra a developers.facebook.com/apps → Crear app → tipo Empresa/Business → agrega el producto Instagram (API con inicio de sesión de Facebook).
      4. Abre el Explorador de la API Graph, elige tu app y marca los permisos instagram_basic, instagram_manage_insights, pages_read_engagement y pages_show_list → Generate Access Token.
      5. En el mismo explorador consulta me/accounts?fields=instagram_business_account: el número dentro de instagram_business_account es tu IG_USER_ID.
      6. Haz que el token dure 60 días: en Depurador de tokens pega el token → Extend Access Token. Ese es tu IG_TOKEN.
      7. En GitHub: crown → Settings → Secrets and variables → Actions → New repository secret: crea IG_TOKEN y IG_USER_ID.
      8. Listo: en la próxima corrida aparece "Instagram · Graph API oficial (cuentas leídas)" en esta pestaña. Repite el paso 6 cada ~60 días.

      Para que el robot siga cuentas extra (otras organizaciones o candidatas), agrégalas en data/instagram.json como {"handle": "usuario", "contest": "mu"}. Solo funciona con cuentas profesionales públicas.

      Cómo funciona

      • El robot (GitHub Actions) corre cada ~10 min: Google y Bing Noticias, YouTube, Wikipedia, artículos, Bing Imágenes, posts públicos de Instagram encontrados por búsqueda y, si la conectas, la Graph API oficial de Instagram.
      • El panel vuelve a leer los datos cada 60 s.
      • Forzar una actualización: GitHub → Actions → "Actualizar datos CROWN" → Run workflow.
      • Instagram con estadísticas (opcional): conecta una cuenta profesional de Instagram a una app de Meta y guarda IG_TOKEN e IG_USER_ID en GitHub → Settings → Secrets → Actions. Con eso el robot lee fotos, likes y comentarios de @missuniverse y de las candidatas con cuenta profesional.
      Datos públicos: Wikipedia, Google/Bing Noticias, YouTube, Instagram (embeds oficiales) y prensa. Uso editorial; respeta los créditos.
